안녕하세요. 3조 발표자 김성겸입니다.
저희 팀은 국내에 부족한 지역 관광 정보를 알려드리기 위해 웹사이트를 개발하였습니다.

"먼저 팀원을 소개드리겠습니다..
저는 팀장으로 전체적인 프로젝트 관리와 JavaScript 기능 구현을 맡았고.
이희준 팀원은 지역 소개 페이지의 콘텐츠 구성과 CSS 디자인을 담당했습니다.
박현정 팀원은 메인 페이지의 구조 설계와 스타일링을 맡아 웹사이트의 전체 분위기를 완성해주었습니다.

이제 이 프로젝트의 배경을 말씀드리겠습니다.
우리나라 관광 산업은 각 지역의 고유한 매력을 잘 전달한다면
국내외 관광객 유치에 큰 잠재력이 있는 분야입니다.
하지만 기존의 관광 정보는 체계적으로 정리되지 않았거나,
사용자 입장에서 직관성이 떨어지는 경우가 많았습니다.
이러한 문제점을 해결하고자, 지역 정보를 쉽게 탐색할 수 있는 웹사이트를 기획하고 제작했습니다."

"저희 웹사이트는 전국 17개 지역과 총 68개 도시의 데이터를 하나로 모았습니다.
슬라이더와 지도 기능을 통해 사용자가 지역 정보를 직관적으로 탐색할 수 있도록 했습니다.
이를 통해 지역 경제 활성화와 관광 산업 발전에 긍정적인 영향을 줄 수 있을 것으로 기대합니다."


<html>
html은 크게 3가지로 나눴습니다. 메인html, 지역html, 맵html

첫 번째로 메인 html에서는 메뉴바와 맵으로 갈 수 있는 지도 아이콘이 있고 가시성을 위해 슬라이드와 각 지역 대표 이미지를 첨부하였스며 클릭시 해당페이지로 이동이 가능합니다.

지역 페이지에서는 지역 메뉴에서 각 도시를 클릭시 설명글과 이미지가 바뀌게 되는 기능이 있습니다.

마지막으로 지도 페이지는 정확한 위치를 파악 할 수 있도록 네이버 지도 API를 활용하여 지도페이지에 첨부하였습니다.


<css>
"css에서는 ‘나눔스퀘어네오’ 폰트를 사용하여 한국적인 느낌을 살렸고,
반응형 웹 디자인을 통해 모바일과 데스크톱 환경 모두에서 자연스럽게 작동되도록 했습니다.
또한, 모든 박스에 고정된 값을 입력하여 확대/축소 시에도 콘텐츠가 깨지지 않도록 했습니다.
그라데이션과 입체감을 활용해 시각적인 완성도를 높였습니다."


<js>
javascript는 웹사이트의 핵심 기능을 구현하는데 사용 되었습니다.

첫번째 지도 위치 제어 기능을 구현하기 위해서 이 코드 처럼 초기 위치와 줌을 설정해 놓은 함수를 만들었습니다. 후에 네이버 지도 api를 로드 후 이 함수를 호출하여 구현했습니다.

다음으로 설명드릴 기능은 메뉴바의 좌우 스크롤 제어입니다.
화면 상단의 지역 메뉴는 공간이 제한되어 있어, 모든 항목을 한 번에 보여주기 어렵습니다.
이를 해결하기 위해, 사용자가 왼쪽 또는 오른쪽 화살표 버튼을 클릭하면
메뉴가 부드럽게 좌우로 스크롤되도록 만들었습니다. 코드에서는 메뉴 아이템의 너비를 계산해 한 번 클릭할 때 얼마만큼 이동할지 정하고, scrollBy 메서드에 smooth 속성을 추가해 부드럽게 이동하도록 구현했습니다.

슬라이더 제어 기능은 웹 사이트에 처음 접속했을 때, 주요 지역 이미지와 문구가 자동으로 전환되며 보여지는 부분입니다.
자바스크립트에서 일정 시간마다 자동으로 넘어가고 그에 맞춰 배경이 바뀌게 만들었고 사용자의 편의를 고려해 앞, 뒤로 갈 수 있는 버튼과 현재 사진에 관련된 지역으로 이동이 가능한 링크도 구현해놓았습니다.

지역 데이터 제어 기능은
사용자가 특정 지역 버튼을 클릭시 해당 지역에 대한 제목, 설명, 이미지가 자동으로 갱신됩니다. 이를 위해 각 버튼에 클릭 이벤트를 등록하고, 선택된 지역의 데이터를 코드에 있는 것과 같이 리전데이터 객체에서 가져와 dom 요소에 동적으로 반영하도록 구성했습니다. 현재 코드에는 보이지 않지만 리전데이터에는 모든 지역의 도시에대한 데이터가 담겨있습니다.

마지막으로 저희 웹사이트를 시연 하겠습니다.
"한국 곳곳의 매력을 만나다라는 제목을 클릭시 이 홈화면으로 돌아오는 기능이 있고"
"메뉴 스크롤 기능 과 지역 및 맵 아이콘들이 헤더 부분에 위치해있습니다."
슬라이더와 각 지역을 대표하는 사진을 첨부하여 시각적인 다양성과 집중도를 높였습니다."
"지역 html에는 메뉴버튼을 클릭시 이미지와 내용이 바뀌도록 설정해놓았습니다."
"마지막으로 지도를 만들어 해당하는 지역의 위치를 확인 할 수 있습니다."

이상으로 발표 마치겠습니다. 감사합니다.
